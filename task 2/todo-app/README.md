# Interactive To-Do List App

## Project Description

This is a mini interactive JavaScript application demonstrating DOM manipulation and browser storage. It implements a professional, responsive To-Do list allowing users to add, edit, complete, delete, filter, and persist tasks.

## Features

- Add tasks via input or pressing Enter
- Mark tasks completed (checkbox)
- Edit tasks inline
- Delete tasks
- Filter tasks: All / Active / Completed
- Clear all completed tasks
- Task counter showing remaining tasks
- Persistent storage via `localStorage`
- Responsive layout for mobile and desktop
- Subtle animations and accessible controls

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5 (CDN for base styles)

## DOM Concepts Demonstrated

- `document.querySelector()` and `querySelectorAll()`
- `document.createElement()` and `appendChild()`
- `element.remove()`
- `element.classList.add()` / `remove()` / `toggle()`
- `element.textContent`
- `addEventListener()`
- `localStorage` usage for persistence

## How to Run

1. Open the project folder in VS Code.
2. Open `todo-app/index.html` in Live Server or your browser.
3. Interact with the app: add tasks, edit, complete, delete.

Simple command-line alternative:

```bash
# from the project folder
start todo-app/index.html
```

## Deployment (GitHub Pages)

1. Create a GitHub repository and push the `todo-app` folder contents.
2. In GitHub, go to repository Settings → Pages.
3. Select the `main` branch and the root folder (or `/todo-app` if you prefer).
4. Save and open the generated GitHub Pages URL.
